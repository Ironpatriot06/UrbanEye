# UrbanEye+

## AI-Powered Smart City Incident Reporting & Intelligent Response System

UrbanEye+ is an end-to-end intelligent civic incident response platform combining citizen reporting, AI, machine learning, GIS, and automated municipal workflows.

### Core Pipeline

Citizen / Edge AI / IoT
→ AI Analysis
→ Incident Fusion
→ Severity
→ Priority
→ Routing
→ Assignment
→ Notification
→ Escalation
→ Resolution
→ Verification / Audit

### Technology Stack

- Next.js
- FastAPI
- PostgreSQL
- PostGIS
- Python
- Computer Vision
- YOLO
- Machine Learning
- Redis
- Celery
- Docker

### Repository Structure

- `frontend/` — Web application
- `backend/` — FastAPI backend
- `ml/` — Machine learning models
- `ai/` — AI, computer vision and NLP
- `docs/` — Documentation
